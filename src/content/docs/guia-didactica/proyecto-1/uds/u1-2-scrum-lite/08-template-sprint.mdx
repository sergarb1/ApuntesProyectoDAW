## Plantilla 5: Burndown Chart simplificado

Un **burndown chart** muestra cuánto trabajo queda por hacer día a día. Es la forma más visual de saber si vais por buen camino.

### Tabla de progreso

| Día | Tareas totales | Tareas hechas | Tareas pendientes |
|-----|---------------|---------------|-------------------|
| Lunes | | 0 | |
| Martes | | | |
| Miércoles | | | |
| Jueves | | | |
| Viernes | | | |

### Cómo interpretarlo

- **Línea recta hacia abajo**: vais bien
- **Línea plana**: no habéis avanzado (problema)
- **Línea que sube**: habéis añadido trabajo (mal signo)

## Plantilla 6: Definition of Done (DoD)

Define qué significa "hecho" para tu equipo. Copia esta lista y personalízala.

### Para features

- [ ] El código compila sin errores
- [ ] Funciona en el navegador del profesor
- [ ] Tiene documentación básica
- [ ] Al menos otra persona lo ha probado
- [ ] Está en la rama principal
- [ ] No tiene errores conocidos

### Para el sprint

- [ ] Todas las features del sprint están en Done
- [ ] El tablero está actualizado
- [ ] Se hizo la retrospectiva
- [ ] Las acciones correctivas están apuntadas
- [ ] El profe ha visto la demo

## Aclaración: "Las plantillas son burocracia"

<Aclaracion icono="⚠️" pregunta="¿Para qué tantas plantillas? No es más fácil programar directamente?">
Las plantillas **no son burocracia**. Son **herramientas de pensamiento**. Te obligan a preguntarte cosas que de otro modo olvidarías: ¿qué riesgos hay? ¿Cómo sé que he terminado? ¿Qué mejorar?

Una plantilla de 5 minutos te ahorra 2 horas de confusión. Si la plantilla te parece inútil, probablemente es porque no la estás usando para pensar, solo para rellenar casillas.
</Aclaracion>

## Mini-chequeo

<details>
<summary>¿Cuáles son las 6 plantillas de SCRUM Lite?</summary>

Respuesta: 1) Sprint Planning, 2) Daily Checklist, 3) Retrospectiva 3Ls, 4) Retrospectiva 4Ls (alternativa), 5) Burndown simplificado, 6) Definition of Done.
</details>

<details>
<summary>¿Cuánto tiempo se tarda en rellenar el Sprint Planning?</summary>

Respuesta: **30 minutos**. Si te tardas más, es porque no tenéis claras las features o las estimaciones. En ese caso, usa T-shirt sizes para ir rápido.
</details>

<details>
<summary>¿Qué es un burndown chart?</summary>

Respuesta: Un gráfico que muestra cuánto trabajo queda por hacer día a día. Si la línea baja, vais bien. Si se queda plana, hay un problema.
</details>

---

## ✅ Resumen en 3 frases

1. Las plantillas te obligan a **pensar antes de programar**: planning (30 min), daily (15 min), retrospectiva (15 min).
2. La **Definition of Done** define qué significa "hecho" para evitar malentendidos.
3. Un **burndown chart** simplificado te dice si vais por buen camino con solo mirar la tabla.
