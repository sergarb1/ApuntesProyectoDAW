## 📬 La idea en una frase

> **C4 documenta tu arquitectura en 4 niveles: Contexto (qué hace), Container (qué tecnologías), Componente (qué partes) y Código (cómo se implementa).**

Cada nivel responde una pregunta diferente.

---

## Los 4 niveles de C4

### Nivel 1: Contexto (System Context)

**Pregunta**: ¿Qué hace mi sistema y quién lo usa?

```
┌─────────────────────────────────────────┐
│           Sistema                       │
│  ┌─────────────────────────────────┐   │
│  │   Tu aplicación de tareas       │   │
│  └─────────────────────────────────┘   │
│         ↑                ↑              │
│    ┌────┴────┐      ┌────┴────┐        │
│    │ Alumno  │      │Profesor │        │
│    └─────────┘      └─────────┘        │
└─────────────────────────────────────────┘
```

| Elemento | Descripción |
|----------|-------------|
| **Tu sistema** | App de tareas para gestión de alumnos |
| **Alumno** | Crea y gestiona sus tareas |
| **Profesor** | Ve el progreso de sus alumnos |

### Nivel 2: Container

**Pregunta**: ¿Qué tecnologías componen mi sistema?

```
┌─────────────────────────────────────────┐
│         App de Tareas                   │
│                                         │
│  ┌───────────┐    ┌───────────────┐    │
│  │ Frontend  │    │  Backend API  │    │
│  │  (Vue)    │◄──►│   (Node.js)   │    │
│  └───────────┘    └───────┬───────┘    │
│                           │             │
│                    ┌──────┴──────┐     │
│                    │  Base datos │     │
│                    │ (SQLite)    │     │
│                    └─────────────┘     │
└─────────────────────────────────────────┘
```

| Container | Tecnología | Responsabilidad |
|-----------|-----------|-----------------|
| Frontend | Vue + Tailwind | Interfaz de usuario |
| Backend API | Node.js + Express | Lógica de negocio |
| Base de datos | SQLite | Persistencia de datos |

### Nivel 3: Componente

**Pregunta**: ¿Qué partes tiene mi frontend?

```
┌─────────────────────────────────────┐
│         Frontend (Vue)              │
│                                     │
│  ┌──────────┐  ┌──────────────┐   │
│  │  Views   │  │  Components  │   │
│  │          │  │              │   │
│  │ Dashboard│  │ TaskList     │   │
│  │ Login    │  │ TaskForm     │   │
│  │ Tasks    │  │ TaskCard     │   │
│  └──────────┘  └──────────────┘   │
│                                     │
│  ┌──────────┐  ┌──────────────┐   │
│  │  Store   │  │  Services    │   │
│  │ (Pinia)  │  │              │   │
│  │          │  │ TaskService  │   │
│  │ taskStore│  │ AuthService  │   │
│  └──────────┘  └──────────────┘   │
└─────────────────────────────────────┘
```

### Nivel 4: Código

**Pregunta**: ¿Cómo se implementa un componente concreto?

```
┌─────────────────────────────────────┐
│         TaskService                 │
│                                     │
│  + getAll(): Task[]                 │
│  + getById(id): Task                │
│  + save(task): Task                 │
│  + delete(id): void                 │
│  - repository: TaskRepository       │
└─────────────────────────────────────┘
```

## Cuántos niveles documentar para Proyecto 2

| Nivel | ¿Necesario? | Tiempo |
|-------|-------------|--------|
| **1 - Contexto** | ✅ Siempre | 15 min |
| **2 - Container** | ✅ Siempre | 20 min |
| **3 - Componente** | ⚠️ Recomendado | 30 min |
| **4 - Código** | ❌ Solo si lo piden | 30+ min |

**Mínimo**: Niveles 1 y 2. Son 35 minutos y dan una visión completa de tu arquitectura.

---

## Aclaración: "¿Necesito los 4 niveles?"

<Aclaracion icono="🤔" pregunta="¿Tengo que documentar los 4 niveles de C4?">
Para un proyecto de módulo, **no necesitas los 4**. Documenta:

- **Nivel 1 (Contexto)**: obligatorio. Qué hace tu app y quién la usa
- **Nivel 2 (Container)**: obligatorio. Qué tecnologías usas
- **Nivel 3 (Componente)**: recomendado. Qué partes tiene tu frontend
- **Nivel 4 (Código)**: opcional. Solo si el profesor lo pide

**Los niveles 1 y 2 son suficientes** para demostrar que entiendes la arquitectura de tu proyecto.
</Aclaracion>

## ✅ Resumen en 3 frases

1. El **modelo C4** documenta la arquitectura en 4 niveles: **Contexto** (qué hace), **Container** (tecnologías), **Componente** (partes), **Código** (implementación).
2. Para Proyecto 2, documenta **mínimo 2 niveles** (Contexto y Container): son 35 minutos y dan una visión completa.
3. C4 es como un **zoom**: desde lo general hasta lo específico. El profesor puede hacer zoom en el nivel que le interese.
