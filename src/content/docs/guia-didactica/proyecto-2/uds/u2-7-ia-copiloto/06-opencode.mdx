## Qué es opencode

opencode es un **agente de IA para desarrollo de software** que:

- Se ejecuta en la **terminal** (TUI: interfaz de texto)
- Trabaja sobre tu **repositorio** (entiende tu código y tus archivos)
- Puede **leer, editar y ejecutar** comandos
- Soporta **múltiples modelos**: Claude, GPT, Gemini y otros
- Es **código abierto** y gratuito

A diferencia de los asistentes de editor que solo sugieren código,
opencode **ejecuta tareas**: le pides "añade autenticación con email"
y él planifica, modifica los archivos necesarios, ejecuta los tests y
te muestra el resultado.

---

## Cómo se ve: la TUI

Al abrir opencode en la terminal, ves una **interfaz de conversación**:

```
┌─────────────────────────────────────────────┐
│  opencode — proyecto: mi-app                │
│                                             │
│  Tú: añade una página de perfil             │
│  ▸ opencode: leyendo models/user.js...      │
│  ▸ opencode: creando views/perfil.vue       │
│  ▸ opencode: ✓ tests pasan (12/12)          │
│                                             │
│  ⌨️  escribe tu petición...                 │
└─────────────────────────────────────────────┘
```

Trabajas con **teclado**: escribes peticiones, y opencode responde con
acciones y texto. Puedes pedirle explicaciones, cambios de código,
revisiones o que ejecute comandos.

---

## Cómo conseguirlo e instalarlo

opencode se instala con npm (necesitas Node.js):

```bash
# Instalar opencode globalmente
npm install -g opencode-ai

# Comprobar que está instalado
opencode --version

# Abrirlo en tu proyecto
cd mi-proyecto
opencode
```

> Es **código abierto**, así que puedes ver su código y su documentación
> en su repositorio oficial.

---

## Cómo funciona la capa gratuita

opencode no te obliga a pagar para empezar. Tienes **dos vías gratuitas**:

### 1. opencode Zen

opencode incluye un plan con **capa gratuita** que te da acceso a modelos
de IA sin coste. Es la forma más sencilla de empezar: instalas, abres y
ya puedes trabajar.

### 2. OpenRouter

opencode se integra con **OpenRouter**, un proveedor que da acceso a
muchos modelos. OpenRouter también ofrece **modelos gratuitos** (con
límites de uso), lo que te da otra vía para usar opencode sin pagar.

<Aclaracion icono="💡" pregunta="¿Qué significa 'capa gratuita amplia'?">
Que puedes usar opencode con modelos de IA **sin coste inicial**. Tanto
**opencode Zen** como **OpenRouter** ofrecen modelos gratuitos.

Eso no significa "ilimitado": las capas gratuitas suelen tener límites
de uso (peticiones por minuto/día, modelos concretos). Para un proyecto
de clase, es más que suficiente. Si algún día necesitas más, puedes
configurar tu propia clave de un proveedor de pago.

La regla en este curso: **empieza con la capa gratuita**. No necesitas
pagar nada para aprender a trabajar con un agente de IA.
</Aclaracion>

## Primeros pasos con opencode

### 1. Abre tu proyecto

```bash
cd tu-proyecto
opencode
```

### 2. Pide una tarea sencilla

> "Explícame qué hace este proyecto y cómo está organizado"

opencode leerá tu código y te dará un resumen. Es la mejor forma de
empezar: que te muestre qué entiende de tu repositorio.

### 3. Pide un cambio concreto

> "Añade una función que calcule el total del carrito, con su test"

opencode hará el cambio, ejecutará el test y te mostrará el resultado.

### 4. Pide una revisión

> "Revisa mi código y dime qué se puede mejorar"

opencode te dará sugerencias concreta, citando archivos y líneas.

## Atajos y comandos útiles

| Acción | Cómo |
|--------|------|
| Enviar petición | `Enter` |
| Cancelar respuesta | `Esc` (o `Ctrl + C`) |
| Nueva conversación | `/new` |
| Ver ayuda | `/help` |
| Cambiar de modelo | `/model` |
| Salir | `Ctrl + D` o `/quit` |

## opencode como estándar del curso

Hemos elegido opencode porque:

- 🆓 **Gratis para empezar**: capa gratuita con opencode Zen y OpenRouter
- 🧩 **Multi-modelo**: no dependes de una sola empresa de IA
- 🔧 **Extensible**: soporta skills (vistos en la sección 05) y herramientas
- 🖥️ **Vive en la terminal**: integrado con Git y tu flujo de trabajo
- 📖 **Código abierto**: puedes entender cómo funciona y confiar en él
