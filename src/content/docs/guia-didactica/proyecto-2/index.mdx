## ¿Qué es Proyecto 2?

Proyecto 2 es la continuación del módulo. Partes de lo aprendido en Proyecto 1
y lo conviertes en un **producto completo y profesional**: aplicación web
Full-Stack, desplegada, monitorizada y con procesos de calidad.

### Las 9 unidades

| UD | Qué harás | Enfoque |
|----|-----------|---------|
| 📋 **UD 2.1: Requisitos Avanzado** | Refinamiento y criterios de aceptación | Análisis |
| 🔄 **UD 2.2: SCRUM Avanzado** | Métricas, burndown, retrospectivas | Metodología |
| 🌿 **UD 2.3: Git Avanzado** | GitFlow, hooks, CI/CD básico | Control versiones |
| 🏗️ **UD 2.4: Patrones de Diseño** | Patrones creacionales, estructurales, comportamiento | Arquitectura |
| 📐 **UD 2.5: Diagramas** | C4, UML esencial, secuencia, infraestructura | Modelado |
| 🤖 **UD 2.6: IA como Copiloto** | LLMs, prompt engineering, testing con IA | Herramientas |
| ☁️ **UD 2.7: Despliegue** | Docker, CI/CD, zero-downtime | DevOps |
| 📊 **UD 2.8: Monitorización** | Prometheus, Grafana, logs estructurados | Operaciones |
| 🚀 **UD 2.9: Propuesta Final** | Ejemplos de proyectos Full-Stack | Práctica |

### Evaluación

Cada UD se evalúa de forma independiente. Consulta la guía de evaluación
para conocer los criterios y pesos de cada unidad.
