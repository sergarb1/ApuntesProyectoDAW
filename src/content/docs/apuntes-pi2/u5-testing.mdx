## Objetivos de aprendizaje

Al terminar esta unidad serás capaz de:

- **Explicar** por qué los tests son esenciales para cualquier proyecto
- **Distinguir** entre tests unitarios, de integración, funcionales y manuales
- **Decidir** qué partes de tu proyecto merecen test automatizado
- **Escribir** tests básicos con herramientas reales (Jest, Vitest, JUnit)
- **Ejecutar** una batería de pruebas manuales completa antes de una entrega
- **Configurar** un flujo de trabajo donde los tests eviten errores en equipo
- **Aplicar** una checklist de calidad que cubra todos los aspectos críticos

## Competencias que desarrollarás

| Competencia | Cómo se trabaja |
|-------------|-------------------|
| **Pensamiento crítico** | Decidir qué probar y qué no, priorizar esfuerzo |
| **Resolución de problemas** | Detectar y diagnosticar fallos con tests |
| **Trabajo en equipo** | Compartir responsabilidad de calidad |
| **Comunicación técnica** | Documentar comportamiento esperado con tests |
| **Autonomía** | Saber que tu código funciona antes de entregarlo |
