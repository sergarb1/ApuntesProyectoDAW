## Objetivos

Al final de esta unidad serás capaz de:

1. **Decidir** si tu proyecto necesita un framework y cuál elegir
2. **Diseñar** componentes con responsabilidad única y props claras
3. **Gestionar** el estado local y global sin over-engineering
4. **Optimizar** el rendimiento: imágenes, peticiones, renderizado
5. **Mejorar** la accesibilidad: contraste, teclado, ARIA, labels
6. **Probar** la interfaz con usuarios reales (método de 3 personas)
7. **Aplicar** una checklist completa antes de cada entrega
