  de **cualquier error** que pueda exponer o destruir tus datos.

## Mapa de la unidad

La unidad se divide en **8 puntos** más un cierre. Cada punto construye
sobre el anterior:

| # | Punto | Idea clave |
|---|-------|------------|
| 01 | Seguridad no es opcional | Por qué importa incluso en proyectos de clase |

## Objetivos de aprendizaje

Al terminar esta unidad serás capaz de:

- **Identificar** los cuatro problemas de seguridad más comunes en web
- **Prevenir** inyecciones SQL usando consultas parametrizadas
- **Almacenar** contraseñas de forma segura con bcrypt y salt
- **Validar** todos los datos de entrada en el servidor
- **Gestionar** secretos con variables de entorno, nunca hardcodeados
- **Implementar** autenticación básica con JWT y control de roles
- **Desplegar** con HTTPS y configurar CORS correctamente
- **Aplicar** una checklist completa de seguridad antes de entregar

## Competencias que desarrollarás

| Competencia | Cómo se trabaja |
|-------------|-----------------|
| **Pensamiento crítico** | Evaluar riesgos y decidir qué proteger primero |
| **Resolución de problemas** | Detectar vulnerabilidades y aplicar soluciones |
| **Responsabilidad** | Proteger datos de usuarios como si fueran tuyos |
| **Comunicación técnica** | Documentar decisiones de seguridad para el equipo |
| **Autonomía** | Saber que tu aplicación resiste ataques básicos |
